# AI Alarm

브라우저에서 실행되는 D-Day 알람 및 5단계 진행 시각화 웹앱입니다.

## 사용 방법

1. 웹앱을 열고 **새 알람 등록**을 선택합니다.
2. 제목, 시작일, 목표 날짜와 시간을 입력합니다.
3. 브라우저 탭을 열어 둡니다. 목표 시각이 되면 알람 창과 반복음이 실행됩니다.
4. 소리가 나지 않으면 페이지에서 사운드 버튼을 한 번 눌러 브라우저의 오디오 재생을 허용합니다.

알람과 기록은 현재 브라우저의 `localStorage`에만 저장됩니다. 다른 기기나 브라우저와 동기화되지 않습니다.

## AI 비용과 API 키

- API 키가 없으면 비용 없는 내장 테마 생성기를 사용합니다.
- 사용자가 자신의 Gemini API 키를 입력한 경우에만 Gemini API를 호출합니다.
- API 사용량과 비용은 입력한 키의 소유자에게 적용됩니다.
- 브라우저 저장소는 비밀 저장소가 아닙니다. 공용 기기에서는 API 키를 입력하지 마세요.
- 개발자 API 키를 소스 코드나 Git 저장소에 추가하지 마세요.

## 중요한 제한

- 브라우저가 완전히 종료된 상태에서는 알람이 울리지 않습니다.
- 운영체제나 브라우저의 절전 정책에 따라 백그라운드 탭의 알람이 지연될 수 있습니다.
- GitHub Pages는 정적 호스팅이므로 서버 비밀키를 보관할 수 없습니다.

## 로컬 실행 및 테스트

`index.html`을 브라우저에서 열거나 정적 파일 서버로 실행합니다.

```powershell
node --test alarm.test.js
```

테스트는 목표 시각 자동 알람의 중복 방지와 잘못된 날짜 입력 차단을 확인합니다.
